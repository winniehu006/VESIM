# VESIM 操作手册

本手册面向 Windows 便携版使用者，覆盖下载启动、首次登录、各功能页面的使用方式与 Windows 下的能力边界。配置细节见[附属手册](REFERENCE.md)，开发 / 发版见[维护手册](MAINTENANCE.md)。

## 1. 下载与启动

1. 打开 <https://github.com/winniehu006/VESIM/releases/latest>，下载最新的 `vesim_*_windows_amd64.zip`。
2. 解压到任意目录（路径建议不含中文与空格以外的特殊字符），目录需可写。
3. 双击 `start-vesim.bat`。脚本会：
   - 创建 `config\`、`data\` 目录；
   - 若 `config\config.yaml` 不存在，从 `config\config.example.yaml` 复制；
   - 读取 `config.yaml` 中的 `server.port`，延迟约 3 秒后打开 `http://localhost:<端口>`；
   - 在前台运行 `vesim.exe`；**关闭该窗口即停止服务**。
4. 浏览器打开 <http://localhost:7575>（若改过端口，以脚本显示的为准）。

校验发布包：对照 Release 说明中的 SHA256 与随附 `.sha256` 文件，例如 v2.1.38 为 `1ed05c63116e545e1ff563bae2c8c027c65cedadc24ae5b9689d6b89dbc48752`。

> 若 `start-vesim.bat` 未自动打开浏览器，手动访问脚本显示的地址即可。若该端口被其他程序占用，控制台会在日志中提示并顺延 WebRTC UDP 端口，但 HTTP 端口仍需自行修改配置。

## 2. 首次登录

1. 默认账号 `admin` / `admin`。登录后若提示弱密码，会弹出「当前密码 / 新密码 / 确认新密码」窗口，输入后点「更新密码并进入」。
2. 随后出现《VESIM 最终用户许可与免责声明》，必须手动输入 **「我同意并确认」** 才能点「同意并继续」；点「拒绝并卸载」会执行卸载并终止服务。请在使用前阅读其中四条声明（仅个人学习研究、禁止违法用途、底层风险自担等）。
3. 后续可在 **设置 → 安全** 输入当前密码与新密码，点「更新凭证」。若密码由环境变量 `PROXY_WEB_PASSWORD` 管理，则需在环境中修改并重启。

## 3. 界面总览

| 页面 | 作用 |
| --- | --- |
| 连接总览（Dashboard） | 设备在线状态、连接焦点、Fleet 汇总、流量分析 |
| 设备管理（Devices） | 扫描 / 添加设备，设备详情与各类配置 Tab |
| 短信中心（Sms） | 会话、历史短信、发送短信与联系人 |
| 代理管理（Proxy） | 前置代理 / 出站代理、国家规则、实例启停 |
| 电话（Phone） | 呼叫模式、拨号、来电接听、通话控制、MCP 音频连接 |
| 自动任务（AutomaticTasks） | 定时任务、立即运行、运行历史 |
| 命令中心（Commands） | 命令对话、余额查询、运营商规则 |
| 实时日志（Logs） | SSE 实时日志，筛选、搜索、暂停、导出 |
| 系统设置（Settings） | 密码、系统信息、MCP、WebDAV 归档、通知渠道 |
| 呼叫设置（UtServices） | 呼叫前转、主叫号码显示、呼叫限制（UT/Simservs） |

## 4. 各页面操作要点

### 4.1 连接总览

- 顶部刷新按钮更新数据；设备状态约每 5 秒轮询，流量分析约每 60 秒轮询。
- 用搜索框与「全部 / 在线 / 离线」分段筛选设备。
- 单击设备卡聚焦该设备，双击进入设备详情。
- 设备列表为空时点「管理设备」跳转到设备管理。

### 4.2 设备管理

- 全局操作：**刷新**、**重新扫描**、**添加设备**。
- 选中设备后，详情头部可：打开短信、轮换 IP、重启模组、重连 VoWiFi。
- 详情含 6 个 Tab：
  - **概览**：设备信息、当前流量分析、E911 设置；
  - **eSIM**：配置文件下载 / 启用 / 禁用 / 重命名 / 删除、通知；
  - **AT**：发送 AT 命令并查看返回；
  - **USSD**：发起 / 继续 / 取消 USSD 会话；
  - **卡策略**：查看与设置指定 ICCID 的策略；
  - **设备配置**：保存配置、删除设备、重试 SIM PIN。
- eSIM 支持激活码或二维码 / PDF；SIM PIN 字段只填**环境变量名**（如 `VESIM_SIM_PIN_READER1`），不要写明文。

### 4.3 短信中心

- 三栏布局：左侧设备栏、中间会话列表、右侧会话区。
- 会话列表支持搜索、新建消息、删除会话；会话区支持刷新、加载更多、删除单条短信。
- 点「新消息」→ 选择发送设备 → 输入号码或从联系人选择 → 输入内容 → 发送。发送前会显示编码、分段与字数预估。
- 查看通知类短信时，顶部会出现「返回最新短信」提示。
- 联系人可从 iOS / Google / Samsung / 小米 / 华为 / OPPO / vivo 导出的 vcf / csv 导入。

### 4.4 代理管理

- 两个 Tab：**前置代理**（默认）与**出站代理**。
- 前置代理：新增 / 编辑 / 删除、国家规则管理、每分钟自动检测与手动刷新。同一国家有多个节点时，可结合 VoWiFi 优先选用 UDP 正常的节点。删除前置代理会级联删除其国家规则并恢复直连。
- 出站代理：新增 / 编辑 / 删除实例，绑定设备，选择 SOCKS5 或 HTTP，设置监听地址 / 端口与认证，然后启动 / 停止 / 重启。
- 代理可用性涉及 SIM 国家规则、公共 DNS UDP 与实测出口三类信息，含义见 [`proxy-diagnostics.md`](proxy-diagnostics.md)。

### 4.5 电话

- 顶部可「连接 MCP」用于浏览器音频通话；需授权麦克风并保持页面打开。
- 选择语音设备与模式：**WiFi calling**、**蜂窝数据**、**VoLTE（模组 IMS）**、**模组直拨**。每种模式旁会显示不可用原因（例如 Windows 下无模组设备）。
- WiFi calling 需先打开「启动」开关；蜂窝数据可选「仅打电话时开」或「长时间开启」。
- 拨号：输入号码或使用拨号键盘，可设置「本卡区号」，然后选择**仅听呼叫**或**双向呼叫**。
- 来电可拒接、仅听接听、麦克风接听；通话中可静音、保持、DTMF 键盘、挂断、加联系人，并可在 15 秒内接管 / 恢复通话方式。
- 侧栏提供联系人与通话记录。
- 页面在非 HTTPS（且非 localhost）环境下会禁止麦克风，相关要求见 [`https-webrtc.md`](https-webrtc.md)。
- 呼叫前转、号码显示、呼叫限制在 **呼叫设置（UtServices）** 页面，仅对已开启 WiFi calling 的设备可用，一次只改一项。

### 4.6 自动任务

- 点「新建任务」，选择设备 / Profile / 任务类型 / 周期 / 时间 / 时区 / payload / 重试与通知，保存后启用。
- 列表支持启用 / 停用开关、**立即运行**（排队并打开运行历史）、查看历史、编辑、删除（需确认）。
- 页面约每 10 秒刷新一次。

### 4.7 命令中心

- 选设备后输入命令（如 `/balance`），事件时间线会实时更新；支持刷新、加载更早、清除历史。
- 危险命令快捷动作（切换 eSIM、VoWiFi 通话、切换公网 IP）带确认弹窗与参数。
- 余额抽屉可查询余额、编辑内置 / 自定义运营商规则、手动录入或清除余额。

### 4.8 实时日志

- 打开页面即通过 SSE 连接日志流；启动时加载最近 500 条，最多缓存 1000 条。
- 支持级别筛选（全部 / DEBUG / INFO / WARN / ERROR）、搜索、自动追尾。
- 可暂停 / 继续、导出为 txt、清空当前缓存。
- MCP 工具调用日志可在此搜索 `MCP tool`。

### 4.9 系统设置

- **安全**：修改登录密码。
- **系统信息**：检查更新、查看配置路径与项目主页、打开 API 文档（`/api/docs`）、切换经典主题与中英文界面、自动接听设置。
- **MCP 接入**：开关、令牌管理与诊断，见[附属手册](REFERENCE.md)与 [`mcp.md`](mcp.md)。
- **WebDAV 归档**：远端备份设置，见 [`webdav-archive.md`](webdav-archive.md)。
- **通知**：Telegram、飞书、个人微信、企微机器人、QQ、Bark、Email、Pushplus、Webhook、企微 Webhook 共 10 个渠道，多数支持「测试通知」；可按渠道设置推送设备。

## 5. Windows 下的能力边界

Windows 便携包**不会发现真实模组设备**，这是预期行为，并非故障：

- QMI / MBIM / AT 访问、VoWiFi、USB 音频、按网卡绑定出站、udev 热插拔均需要 Linux 主机与 USB 直通。
- 模组直拨音频、ALSA 音频与原生 AMR / MP3 编解码在非 Linux 环境不可用，电话页相应模式会显示禁用原因。
- 因此 Windows 版适合：体验 Web 控制台与界面、管理本地数据、测试 MCP 接入。需要驱动真实模组请使用上游 [HiDeck](https://github.com/yibaiba/hideck)。

## 6. 日常维护操作

| 场景 | 操作 |
| --- | --- |
| 停止服务 | 关闭运行 `start-vesim.bat` 的窗口，或按 `Ctrl+C` |
| 修改端口 | 编辑 `config\config.yaml` 的 `server.port`，重启后以脚本显示的地址访问 |
| 保留数据升级 | 保留 `config\`、`data\`，替换新版本的 `vesim.exe` 等发布文件 |
| 查看日志 | `logs\app-YYYY-MM-DD.log`，或打开「实时日志」页面 |
| 备份 | 使用「设置 → WebDAV 归档」，或自行复制 `data\`、`config\` |
| 卸载 | 接受声明前点「拒绝并卸载」，或停止服务后手动删除解压目录 |

更多配置项、环境变量和排障见[附属手册](REFERENCE.md)。
